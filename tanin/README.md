# TanIn（たんいん）

中学生〜社会人が「単位換算」と「オームの法則」を練習できる Web アプリです。
スマホのブラウザからも PC のブラウザからも快適に使えることを最優先に作っています。

- 幅 375px（iPhone SE 相当）でも横スクロールなしで全機能が使えます
- **スマホでは画面下にタブバーが固定**され、アプリのように親指で切り替えられます
  （PC では従来どおり画面上部のタブ。サイドバーは使いません）
- 「ホーム画面に追加」すると、ブラウザのバーなしで開きます（iOS / Android）
- 背景は明るい（ライト）画面に固定。端末がダークモードでも見た目は変わりません
- 解説は小学生でも読めるように、「① 式 → ② 数を入れる → ③ 答え → ポイント」の順で書いています
- ユーザー登録・ログインなし。サーバーにデータを保存しません

## 起動方法

### はじめて使うとき（クローン）

このリポジトリには複数のアプリが入っていて、TanIn は `tanin/` フォルダで完結しています。
以降のコマンドはすべて `tanin/` の中で実行してください。

```bash
git clone https://github.com/HirokiKenmochi/apps.git
cd apps/tanin
```

すでにこのPCにある場合は `cd ~/projects/tanin/tanin` で移動します。

### uv を使う場合

```bash
uv venv
uv pip install -r requirements.txt
uv run streamlit run app.py
```

### pip を使う場合（uv が入っていないとき）

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

起動すると次の URL が表示されます。

- PC から: `http://localhost:8501`
- 同じ Wi-Fi のスマホから: 起動時に表示される **Network URL**（`http://192.168.x.x:8501`）

ローカル起動だけなら、インターネット上には公開されません。

## インターネットに公開する（Streamlit Community Cloud）

無料で、誰でもスマホから開ける URL を作れます。**GitHub アカウントでのログインが必要なので、
次の手順はご本人の操作でお願いします**（所要 5 分ほど）。

1. https://share.streamlit.io を開く
2. **Continue with GitHub** でログイン（このリポジトリを持っている GitHub アカウント）
3. リポジトリが Private の場合、途中で「private リポジトリへのアクセス許可」を求められるので許可する
4. **Create app** →「Deploy a public app from GitHub」を選び、次を入力
   - Repository: `HirokiKenmochi/apps`
   - Branch: `main`
   - Main file path: `tanin/app.py`（リポジトリ直下ではなく `tanin/` フォルダの中）
   - App URL: 好きな名前（例 `tanin`）→ 公開 URL は `https://tanin.streamlit.app`
5. **Deploy** を押す。1〜3 分でビルドが終わり、URL が使えるようになります

補足

- 公開後は `git push` するたびに自動で再デプロイされます
- 学習履歴はブラウザのセッションにだけ残ります。サーバーには保存されないので、
  同じ URL を複数人が開いてもデータは混ざりません
- 依存関係は `requirements.txt`（実行に必要なものだけ）が読まれます

## 今後の運用（編集 → 公開 → 端末で最新化）

```
[PC で編集] → ./scripts/deploy.sh "メモ" → [公開版が自動で最新に]
                                              ↓
                     [スマホ] 開きっぱなしの画面は「⟳ 最新版に更新」を押す
```

1. **編集する** … `~/projects/tanin/tanin` のファイルを直す
2. **デプロイする** … `./scripts/deploy.sh "変更内容のメモ"`
   （テスト → push → 公開版に反映されたか確認まで自動。ふつう 10 秒ほどで `✅`）
3. **端末で最新にする** … 新しく開けば最新版。すでに開いている画面は、
   いちばん下の **「⟳ 最新版に更新」** ボタンを押す（2 回タップで実行）。
   **学習履歴はブラウザに保存されているので、更新しても消えません**

補足

- サーバー側（公開版）は push の 1〜2 秒後に自動で最新コードを取り込みます。
  Streamlit Community Cloud に「外から再デプロイを叩く API」はないので、
  アプリ内のボタンは**画面を最新にする**役割です
- 学習履歴はその端末のブラウザ（localStorage）に保存されます。画面を更新しても、
  デプロイでサーバーが再起動しても残ります。サーバーには送られません
- 別の端末に移したいときは「成績」タブの JSON 書き出し／読み込みを使ってください
- どのバージョンが動いているかは、画面いちばん下の「バージョン: …」で分かります

## 公開版へ反映する（コマンドの詳細）

```bash
./scripts/deploy.sh "変更内容のメモ"
```

このスクリプトが、テスト → Lint → `static/version.txt` の更新 → コミット → push →
**公開版が新しいバージョンを返すまで見張る**、まで一気にやります。

- 反映されると `✅ 反映されました！` と表示されます（通常 push の 1〜2 秒後に取り込まれます）
- 5 分待っても反映されないときは、Streamlit 側で処理が滞っています。表示される手順どおり
  公開ページ右下の **Manage app → ⋮ → Reboot app** を押せば 1〜2 分で最新版になります
- 反映されたかは、アプリ画面いちばん下の **「バージョン: …」** でも確認できます
  （`<アプリのURL>/~/+/app/static/version.txt` を開いても同じ値が見られます。
  Streamlit Community Cloud はアプリを `/~/+/` の下で配信するため、このパスになります）

手で push しても自動反映されます（GitHub の webhook が Streamlit に push を通知します）。
スクリプトは「反映されたことの確認」までやってくれる点が違いです。

## 機能一覧

### 1. 単位換算（Converter）

- 「量」→「変換元」→「変換先」を選び、数値を入れると即座に結果表示
- 対応する量と単位（全 11 量・80 単位）

| 量 | 単位 |
| --- | --- |
| 長さ | nm, µm, mm, cm, m, km, in, ft, yd, mile, 海里, 尺, 間 |
| 質量 | µg, mg, g, kg, t, lb, oz, 貫, 匁 |
| 面積 | mm², cm², m², a, ha, km², 坪, 反, 町 |
| 体積 | mm³, mL, cm³, L, m³, kL, 米ガロン, 英ガロン, バレル, 升, 合 |
| 時間 | ms, s, min, h, d |
| 圧力 | Pa, hPa, kPa, MPa, bar, atm, mmHg, kgf/cm², psi |
| 力 | N, kN, kgf, dyn |
| エネルギー | J, kJ, MJ, cal, kcal, Wh, kWh, eV |
| 仕事率 | W, kW, MW, PS, HP |
| 速度 | m/s, km/h, ノット, mph |
| 温度 | ℃, K, ℉（オフセット付きの換算式） |

- 変換元と変換先には「選んだ量の単位」しか出てこないので、異なる量の換算は **UI 設計上そもそも選べません**
- 有効数字を 3〜10 桁のスライダーで変更できます
- 丸めが発生した結果には「≈」が付きます（例: `1 坪 ≈ 3.30579 m²`）。ちょうど割り切れるときは付きません（例: `36 km/h = 10 m/s`）
- よく使う組み合わせを「お気に入り」に登録してワンタップで呼び出せます

### 2. 練習問題（Quiz）

- **学習の順番**（練習問題タブの最初の画面）… やさしい順に 11 ステップならんでいます。
  **タイトルをタップすると問題の画面に切り替わります**（一覧は隠れ、問題だけが表示されます）。
  問題画面の上には「← 学習の順番にもどる」と、いま取り組んでいるステップ名・進み具合が出ます。
  各ステップは 5 問正解で「✅ できた」になります
- **YouTube で学ぶ**リンクが、ステップごと・解説の下に付いています。
  既定では「YouTube の検索結果」に飛びます（動画が消えてもリンク切れにならないため）。
  見せたい動画を決めたい場合は、`tanin/quiz.py` の `LEARNING_STEPS` の
  `youtube_url="https://www.youtube.com/watch?v=..."` に URL を入れると、そちらが優先されます

  1. 偶数と奇数を見分ける → 2. かけ算の筆算 → 3. わり算の筆算 → 4. 小数点の動かし方
  → 5. 単位の変換 → 6. オームの法則 → 7. mA・kΩ の計算 → 8. 直列回路 → 9. 並列回路
  → 10. 合成抵抗 → 11. 電力・電力量・熱量

- カテゴリを自分で選ぶこともできます

  **小学生向け（算数）**
  - **偶数と奇数** … 「この中で偶数はどれ？」「37 より大きいいちばん小さい奇数は？」
    「29〜79 に奇数はいくつ？」。一の位を見る見分け方を毎回説明します
  - **かけ算の筆算** … 1けたをかける／2けたをかける／小数のかけ算。
    「くり上がりをたす」「小数点を左に◯つ動かす」まで手順を表示します
  - **わり算の筆算** … 割り切れる問題／答えが小数になる問題／わる数が小数の問題。
    解説は「上の位から順に、どの位に何をたてるか」を 1 行ずつ示します
  - **小数点の動かし方** … 10倍・100倍・1000倍、10・100・1000でわる、「何倍すると◯になる？」
  - **単位の変換** … cm と m、mm と cm、g と kg、mL と L、cm³ と mL、分と秒、時間と分、日と時間

  **理科**
  - オームの法則の基本／単位の換算（mA・kΩ）／直列回路／並列回路／合成抵抗（直並列）／電力・電力量・熱量
- 難易度：やさしい／ふつう／むずかしい
- 問題は毎回ランダム生成（固定の問題リストは持ちません）
- **答えは必ず小数第 2 位までで割り切れる値**になります（小数点の練習だけは第 3 位まで。後述）
- 出題形式は「数値入力」と「4 択」の混在。4 択の誤答は「単位換算を忘れた値」
  「掛け算と割り算を逆にした値」などありがちな間違いから作ります
- 4 択は**横長のボタン**で表示されます。タップすると色が変わって選択状態になり、
  別のボタンを押すと選び直せます。答え合わせのあとは、正解に ⭕️、まちがえた選択に ❌ が付きます
- 解答すると即座に正誤と、計算式つきの解説を表示します。解説は小学生でも読めるように
  「① つかう式 → ② 数を入れる → ③ 答え → ポイント」の 4 ステップで書いています
- わる数が小数になる問題では「両方を 100 倍して 3000 ÷ 5 にすれば筆算できる」、
  単位を直す問題では「1000 をかけるので小数点を右に 3 つ」と、その場でやり方を示します
- 直列・並列の問題には回路図（SVG）が付きます
- オームの法則を使う問題では、解説の下に「三角形」の図が出ます。もとめるものが自動でかくれ、
  V = I × R / I = V ÷ R / R = V ÷ I のどれを使うのかがひと目でわかります
- 「10問チャレンジ」モードでは、連続 10 問のスコアと所要時間が出ます
- 「復習リストから」モードで、間違えた問題だけを解き直せます

### 3. 早見表（Reference）

- **図でわかる 電圧・電流・抵抗**（小学生向けの絵）
  1. 水のたとえ：タンクの水の高さ＝電圧、流れる水の量＝電流、管のせまさ＝抵抗
  2. かん電池（＋−つき）と豆電球で描いた回路の絵。電流が一周する矢印つき
  3. くらべてみよう：電圧を2ばい→電流も2ばい、抵抗を2ばい→電流ははんぶん、を棒の長さで比較
  4. オームの法則の三角形（でんあつ／でんりゅう／ていこう と、たて＝わり算・よこ＝かけ算の目印つき）。
     かくしたい文字を選ぶと、その場でかくれて式が出ます
- **計算のしかた**（けたをそろえた筆算の図つき）
  1. かけ算の筆算（1けたをかける）… くり上がりを位ごとに追う
  2. かけ算の筆算（2けたをかける）… 一の位のかけ算＋十の位のかけ算に分けて足す
  3. 小数のかけ算 … 小数点をわすれて計算し、けた数の合計だけ小数点を左に動かす
  4. わり算の筆算 … たてる・かける・ひく・おろす
  5. わる数が小数のとき … わる数とわられる数を同じだけ 10倍・100倍する
  6. 10倍/100倍/1000倍と小数点の動きの対応表
  7. 単位（A ⇄ mA、kΩ ⇄ Ω、W ⇄ kW）への使い方
- SI 接頭語 24 種（従来の 20 種＋2022 年の第 27 回 CGPM で追加された 4 種）
- SI 基本単位 7 種（定義の根拠となる定数つき）
- 固有の名称をもつ SI 組立単位 22 種（他の SI 単位での表現／SI 基本単位での表現）
- オームの法則・直列並列・電力の公式まとめ
- 非 SI 単位の換算一覧（**単位換算ページと同じデータから自動生成**。表を二重管理していません）
- 検索ボックスで全ての表を横断して絞り込めます

### 4. 成績（Stats）

- カテゴリ別の正答率、連続正解記録、直近 20 問の推移グラフ
- 間違えた問題は復習リストに貯まり、正解すると自動的に消えます
- 学習履歴はその端末のブラウザ（localStorage）に自動保存されます。画面を更新しても、
  アプリが更新されても残ります（サーバーには保存しません）
- 履歴を JSON でダウンロード／アップロードして、別の端末へ移せます
- 「履歴をすべて消す」を押すと、ブラウザに保存したぶんも消えます

## 設計メモ

### 換算係数は Fraction で厳密に持つ

各単位は「その単位 1 個あたりの基準単位での値」を `fractions.Fraction` で保持し、
`結果 = 入力値 × 係数(変換元) ÷ 係数(変換先)` で計算します。float を経由しないので、
往復変換（A→B→A）は厳密に一致します。係数にはすべて出典コメントを付けています
（SI 第 9 版／計量法／国際ヤード・ポンド協定／NIST SP811）。

`Unit.exact` は「係数が 10 進の有限小数として厳密に書けるか」を表します。
1 atm = 101325 Pa は `True`、1 尺 = 10/33 m や 1 坪 = 400/121 m² は `False` です。
表示時には毎回「丸めた結果が厳密値と一致するか」を判定し、しないときだけ「≈」を付けます。

温度だけは係数方式ではなく、オフセット付きのアフィン変換
（`K = 値 × ratio + offset`）で実装しています。

### 答えがきれいになる問題生成

`quiz.py` の中に閉じ込めたロジックです。

1. 候補となる抵抗値・電圧値・電流値の集合からパラメータを抽選する
2. 計算結果が「小数第 2 位までで割り切れる」（`値 × 100` が整数）かを確認する
3. 満たさなければ再抽選。同じパターンで **200 回**（`quiz.MAX_ATTEMPTS`）超えたら、
   そのパターンを諦めて同じカテゴリの別パターンへフォールバック
4. すべてのパターンが失敗した場合は、「構成上かならず整数になる」フォールバック問題を返す

`tests/test_quiz.py` で 1980 問を生成し、すべてが条件を満たすこと、
かつ答えが独立に計算した値と一致することを検証しています。
単位変換の問題は `tanin/units.py` の換算データをそのまま使うので、表を二重管理していません。

### スマホ対応

- `st.set_page_config(layout="centered")`。幅の広い表だけ `st.dataframe(use_container_width=True)`
- ページ切り替えはサイドバーではなく `st.tabs`（サイドバーはスマホだと隠れて気づきにくいため）
- 数値入力は `st.number_input`（矢印ボタンが押しにくい）ではなく `st.text_input` ＋ 自前パース。
  placeholder を目印に `inputmode="decimal"` を付与し、スマホで数字キーパッドが出るようにしています。
  全角数字・カンマ区切りも読み取ります
- ボタン・入力欄・ラジオに `min-height: 44px` を確保する最小限の CSS だけを注入
- 幅 640px 以下では、タブ一覧を `position: fixed` で画面下に固定してアプリ風のタブバーにする。
  背景色は JS でテーマの背景色を読み取って CSS 変数 `--tanin-bg` に入れているので、
  色はハードコードしていない。`env(safe-area-inset-bottom)` で iPhone のホームバーも避ける
- 「ホーム画面に追加」で全画面起動するよう、`apple-mobile-web-app-capable` などの meta を
  JS で親ドキュメントの `<head>` に差し込んでいる
- Streamlit 1.60 でタブの DOM が変わったため、セレクタは `data-testid="stTabs"` /
  `data-testid="stTab"` を使う（旧 `data-baseweb="tab-list"` は当たらない）
- 色は一切ハードコードせず、Streamlit のテーマに任せています。回路図の SVG も `currentColor` を
  使うので、テーマを変えても線と文字が見えます
- 背景は `.streamlit/config.toml` の `[theme] base = "light"` で明るい画面に固定しています。
  端末の設定に合わせたい場合は、この `[theme]` を消すか `base = "dark"` に変えてください
- 幅 375px のブラウザで、4 タブすべて横スクロールが発生しないことを確認済み

## 既知のメモ

- Streamlit Community Cloud は `git pull` のあと、**読み込み済みモジュールをメモリに
  残したままメインスクリプトだけ再実行する**。そのため、モジュールに関数を追加した
  コミットをそのまま反映すると `ImportError` でアプリが止まることがある。
  `app.py` の先頭で `tanin/**.py` の更新時刻を見て、変わっていたら `sys.modules` から
  外して読み込み直すようにして回避している（2026-08-02 に実際に踏んだ）。

- 回路図は `st.html` ではなく `st.markdown(..., unsafe_allow_html=True)` で埋め込んでいます。
  `st.html` は DOMPurify の HTML プロファイルで SVG 要素ごと除去してしまうためです。
- `use_container_width` は Streamlit 1.60 で非推奨（サーバーログに警告が出ます）。
  新しい API に合わせる場合は `width="stretch"` に置き換えてください。
